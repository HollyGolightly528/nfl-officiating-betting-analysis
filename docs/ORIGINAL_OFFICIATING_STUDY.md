# Original officiating investigation (primary study)

The original question precedes the betting analysis: **Do the Dallas Cowboys receive more unfavorable penalty calls than other NFL teams?**

## Requested breakdowns
1. Five completed seasons: 2021, 2022, 2023, 2024, 2025.
2. AFC versus NFC.
3. Every one of the 32 NFL teams, with season-level and pooled comparisons.
4. Dallas versus the full NFL, NFC, and NFC East (Giants, Eagles, Commanders).
5. Both accepted penalties **against** and **benefiting** each team, counts and yards.
6. Penalty type, home/away, game situations, and officiating crew where sourced.
7. Separately assess **questionable/incorrect** calls using independent video review. Penalty counts alone cannot answer this.
8. Visualize seasonal trends, team rankings, Dallas differentials and conference comparisons.
